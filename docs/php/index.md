# Kumpulan Dokumentasi PHP

PHP adalah bahasa pemrograman sisi server yang paling banyak dipakai untuk web. Satu file PHP bisa berisi HTML dan kode yang dieksekusi di server sebelum dikirim ke browser.

## Kenapa PHP

- **Kurva belajar landai** — untuk mencetak "Hello" cukup satu file.
- **Ekosistem besar** — WordPress, Laravel, Symfony, Composer.
- **Hosting di mana-mana** — hampir semua shared hosting mendukung PHP.
- **Terus berkembang** — dari 5.x ke 8.x performa dan fitur melompat jauh (JIT, typed properties, enum, readonly, fibers).
