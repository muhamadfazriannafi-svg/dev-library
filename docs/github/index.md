# Kumpulan Dokumentasi GitHub

Rubrik ini khusus fitur GitHub di luar perintah Git dasar: hosting statis dan otomasi CI/CD.

## Daftar Materi

- [GitHub Pages](/github/github-pages) — hosting gratis untuk situs statis (termasuk VitePress ini).
- [GitHub Actions](/github/github-actions) — otomasi build, test, dan deploy lewat workflow.

## Alur Besarnya

```
push ke main  →  GitHub Actions menjalankan workflow  →  hasil build di-deploy  →  GitHub Pages menyajikannya
```

Poin penting: Pages yang menyajikan, Actions yang mengerjakan.
